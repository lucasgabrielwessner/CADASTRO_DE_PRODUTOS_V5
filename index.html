Como o Bootstrap aceleraria a nossa interface

Bootstrap é uma biblioteca de CSS e JavaScript com componentes prontos. Neste projeto escrevemos o CSS e os modais à mão; com o Bootstrap, a maior parte disso viria pronta, bastando adicionar classes ao HTML.

  • Sistema de grid e container: As classes container, row e col-* organizam o layout e se adaptam sozinhas a celulares e telas grandes, no lugar do nosso .container e das media queries.
  • Formulários e botões prontos: form-control, form-label, btn btn-primary e btn btn-danger substituem o estilo que escrevemos para inputs e botões, com hover e foco já incluídos.
  • Alertas no lugar da nossa mensagem de erro: A caixa vermelha de validação seria um componente alert alert-danger, com variações de cor para sucesso, aviso e informação.
  • Modal nativo da biblioteca: O nosso modal de confirmação equivale ao componente Modal do Bootstrap, que já cuida de fundo escuro, tecla Esc, foco e acessibilidade, usando data-bs-toggle e data-bs-target.
  • Tabelas estilizadas: Com table table-striped table-hover a listagem de produtos ganha linhas zebradas e destaque ao passar o mouse sem CSS extra.

Exemplo: nossa mensagem de erro em Bootstrap

<div class="alert alert-danger" role="alert">
  Informe o nome do produto.
</div>

Para usar, basta incluir o link do CSS e o script do Bootstrap (via CDN) no index.html.
